# ENERGY QUEST — เกมเศรษฐีพลังงาน

เว็บแอปเกมกระดานพลังงานสำหรับใช้ในห้องเรียน เล่นผ่านคอมพิวเตอร์ครูและโทรศัพท์นักเรียน รองรับหลายทีมและซิงก์ข้อมูลแบบเรียลไทม์ผ่าน Firebase Realtime Database

## ไฟล์ในโปรเจกต์
- `index.html` หน้าเว็บหลัก
- `style.css` ธีมพลังงานสีเขียวเข้ม/มิ้นต์
- `app.js` ระบบห้องเกม กระดาน ลูกเต๋า คะแนน และการส่งคำตอบ
- `questions.js` คลังคำถาม แก้ไข/เพิ่มคำถามได้
- `firebase-config.js` จุดใส่ค่าการเชื่อมต่อ Firebase

## วิธีนำขึ้น GitHub Pages
1. สร้าง Repository ใหม่บน GitHub
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไว้ที่ root ของ Repository
3. สร้างโปรเจกต์ที่ https://console.firebase.google.com/
4. เพิ่ม Web App ใน Firebase แล้วคัดลอก Firebase config ไปใส่ใน `firebase-config.js`
5. ใน Firebase เลือก **Build > Realtime Database > Create Database** เลือก location ที่ใกล้ เช่น Singapore
6. ตั้งค่า Rules สำหรับทดลองใช้ในชั้นเรียน (ดูด้านล่าง)
7. ไปที่ GitHub Repository > Settings > Pages > Deploy from a branch > เลือก `main` และ `/root` > Save
8. รอ GitHub Pages เผยแพร่เว็บ แล้วเปิด URL ที่ได้

## Firebase Realtime Database Rules (สำหรับทดลอง)
> กฎนี้เปิดอ่าน/เขียนข้อมูลได้สำหรับผู้ที่มี URL ห้อง จึงเหมาะกับการทดลองในชั้นเรียนเท่านั้น ไม่ควรใช้เก็บข้อมูลส่วนบุคคลหรือข้อมูลสำคัญ หากต้องการใช้งานสาธารณะระยะยาว ควรเพิ่ม Firebase Authentication และตรวจสอบสิทธิ์ฝั่งฐานข้อมูล

```json
{
  "rules": {
    "rooms": {
      "$room": {
        ".read": true,
        ".write": true
      }
    }
  }
}
```

## วิธีเล่น
### ครู
1. เปิดเว็บและกด “สร้างห้องสำหรับครู”
2. แชร์รหัส 6 หลักให้นักเรียน
3. รอทีมเข้าร่วม (แนะนำทีมละ 4–6 คน)
4. กด “เริ่มเกม”
5. เลือกทีมที่เล่น แล้วกดทอยลูกเต๋า
6. เมื่อทีมตกช่อง ระบบสุ่มคำถามตามประเภทช่อง
7. ให้นักเรียนส่งคำตอบจากมือถือ ครูอ่านคำตอบและกด “ถูกต้อง” หรือ “ไม่ถูกต้อง”
8. กด “จบตา / ทีมถัดไป” เพื่อเปลี่ยนทีม

### นักเรียน
1. เปิด URL เดียวกันบนโทรศัพท์
2. กรอกรหัสห้อง
3. กรอกชื่อทีมและสมาชิก
4. เมื่อมีคำถาม ให้ปรึกษากันและส่งคำตอบผ่านมือถือของทีม

## แก้ไขคลังคำถาม
เปิด `questions.js` แล้วเพิ่มรายการตามรูปแบบนี้

```js
{category:"ประหยัดพลังงาน",type:"save",q:"คำถาม...",a:"แนวคำตอบ...",points:3}
```

ประเภทช่องที่รองรับ:
- `question` คำถามการใช้ประโยชน์พลังงาน
- `save` คำถามการใช้พลังงานอย่างประหยัด
- `luck` เสี่ยงโชค
- `challenge` ท้าทาย

## ข้อควรทราบ
- ตัวอย่างคำถามใน `questions.js` เป็นคำถามตั้งต้นตามหัวข้อแหล่งพลังงานและการใช้พลังงานอย่างประหยัด ไม่ใช่การถอดบัตรคำถามทุกใบจากต้นฉบับ สสวท. ครูสามารถแทนที่ด้วยคำถามจากชุดที่โรงเรียนใช้ได้
- ระบบนี้เป็นต้นแบบสำหรับเล่นในห้องเรียน ต้องตั้งค่า Firebase ก่อนจึงจะซิงก์ข้ามอุปกรณ์ได้
- ข้อมูลห้องเกมเก็บใน Firebase Realtime Database; ปิดห้องแล้วสถานะห้องจะเป็น closed
- ไม่ต้องติดตั้ง Node.js หรือ build project สามารถโฮสต์เป็น Static Website ด้วย GitHub Pages ได้
