# ENERGY QUEST — เกมเศรษฐีพลังงาน

เว็บเกมกระดานสำหรับครูควบคุมจากคอมพิวเตอร์ และนักเรียนเข้าร่วมจากมือถือ เล่นเป็นทีม 4–6 คน ซิงก์ข้อมูลผ่าน Firebase Realtime Database

## ไฟล์
- `index.html` หน้าเว็บ
- `style.css` รูปแบบเดิม
- `app.js` ระบบเกมและการเชื่อมต่อ
- `questions.js` คลังคำถาม
- `firebase-config.js` Firebase Web App config
- `firebase-rules.json` กฎฐานข้อมูลสำหรับนำไปวางใน Firebase

## ตั้งค่า Firebase
1. Authentication > Sign-in method > เปิด **Anonymous** ให้เป็น Enabled
2. Realtime Database > Rules: คัดลอกเนื้อหา `firebase-rules.json` ไปวาง แล้วกด Publish
3. ตรวจสอบว่า `firebase-config.js` เป็น config ของ Web App โปรเจกต์เดียวกับ Realtime Database
4. GitHub Pages ใช้ไฟล์ทั้งหมดใน root ของ repository

## วิธีเล่น
### ครู
1. เปิดเว็บและกดสร้างห้อง
2. แชร์รหัส 6 หลักให้นักเรียน
3. รอทีมเข้าร่วม แล้วกดเริ่มเกม
4. เลือกทีมและทอยเต๋า
5. อ่านคำตอบที่นักเรียนส่ง แล้วกดถูกต้อง/ไม่ถูกต้อง
6. กดจบตาเพื่อเปลี่ยนทีม

### นักเรียน
1. เปิดเว็บเดียวกันและกรอกรหัสห้อง
2. ตั้งชื่อทีมและกรอกชื่อสมาชิก 4–6 คน คั่นด้วยเครื่องหมายจุลภาค
3. เมื่อถึงตาทีม ให้ปรึกษากันและส่งคำตอบผ่านมือถือ

## โครงสร้างข้อมูลและสิทธิ์
- `rooms/{room}`: สถานะเกม ทีม คะแนน และคำถามที่แสดงให้นักเรียน
- `answerKeys/{room}/{questionId}`: เฉลย อ่าน/เขียนได้เฉพาะ UID ของครูเจ้าของห้อง
- `submissions/{room}/{questionId}/{teamId}`: คำตอบของทีม ทีมเขียน/อ่านได้เฉพาะข้อมูลของตนเอง ส่วนครูเจ้าของห้องอ่านคำตอบของทุกทีมได้

## ข้อควรทราบ
- เปิด Anonymous Authentication ก่อนทดสอบ
- อย่าเปิด `.read: true` หรือ `.write: true` ที่ root
- เกมนี้เป็นต้นแบบห้องเรียนแบบ client-side; การยืนยันว่าเป็นครูอาศัย UID ผู้สร้างห้อง ไม่ใช่ระบบบัญชีครูของโรงเรียน หากต้องการระบบควบคุมระดับ production ควรใช้ backend/Cloud Functions และบัญชีครูที่ยืนยันตัวตน
- `questions.js` เป็นคลังคำถามตั้งต้น ปรับแก้ได้ตามกิจกรรมของครู
